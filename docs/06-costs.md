# 6. Running-cost options (infrastructure only)

This is a self-funded, speculative concept. There is **no agreed contract, fee, hourly rate or day rate**, and this document deliberately contains **no development charges, effort-based pricing or maintenance fees**. If the owners are interested, scope, ownership, maintenance and commercial terms are discussed separately.

What follows is only what the architecture itself costs to run, so the owners can see it is lightweight. All figures are indicative and must be re-checked with each provider; none has been purchased.

| Item | Indicative cost | Notes |
|---|---|---|
| Static hosting for the Astro site | £0 on common free tiers | Limits and terms change; verify before relying on them |
| Private preview access gate | £0 reported on free tiers | See `09-private-preview-plan.md`; verify terms |
| Domain | Already owned by the venue | No change needed for a prototype |
| Toast Tables / Toast Websites | Venue's own Toast agreement | UK pricing is not published. Not a cost of this site |
| Managed CMS | £0 – not needed | Add later only if the menu source of truth isn't Toast |
| Database / backend | None | Reservations live in Toast |

**Compared with a typical managed WordPress setup**, a static site avoids runtime hosting, plugin licences and routine security patching. The trade-off is that editing is not through a WordPress admin; day-to-day content would come from Toast (menus) or a small content file/CMS decided later.
