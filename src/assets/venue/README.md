# Approved client-review photos

Drop the twelve `client-*.webp` photographs from the website photo pack into this folder.

The 12 files were supplied by the project creator and include The Horse exterior, garden seating, dining interior, hanging sign, pork belly katsu, potato hash and two Sunday roast presentations.

On GitHub: open this folder → **Add file → Upload files**, select the extracted WebP photographs, and commit to `main`. GitHub Pages rebuilds automatically.

The Astro `Photo` component gives priority to `client-` images and falls back to public archive photos or labelled placeholders if a client image is absent.

The source images and some dishes are historical; confirm the restaurant has authorised public use and whether featured dishes are still offered before making this an official website.

Do not upload phone metadata, original large JPGs or image files containing private guest information.
